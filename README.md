# EEDSolver

Experimental electrodynamics simulation project. The current coupled EED and
direct gravity mappings include unvalidated modeling assumptions.

Start with the [electrodynamics and gravity research collection](research/README.md)
for 43 annotated sources, a reading order, and a source-based audit of this
repository. The [field-theory contract](FIELD_THEORY.md) describes the existing
model; it is not evidence that the proposed effects occur in nature.

The [first static-capacitor benchmark](research/capacitor/README.md) provides
a reproducible force calculation, experimental comparison, and source audit.
