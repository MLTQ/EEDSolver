# Local paper cache

The PDF filenames correspond to R01–R46 in [the annotated library](../PAPERS.md).
Only successfully retrieved papers are present. The exact source URL, arXiv
version when available, page count, retrieval date, and SHA-256 are recorded in
[sources.json](../sources.json).

PDFs are local reading copies and are not committed to git. In a fresh clone,
follow the library's source links or download a selected `download.url` to its
recorded `download.path` under `research/`. Respect the source's access terms;
an unavailable file is not a request to bypass a paywall.
